6. Reglas de Negocio

    RN1: El estado de un postulante se mantiene en "Pendiente" hasta que un Administrativo aplique la aprobación final.

    RN2 (Control de Pago): Ningún grupo familiar recibe un espacio fúnebre si el sistema no registra el cobro previo de la cuota de "Afiliación".

    RN3: Los únicos vínculos permitidos para los acompañantes son: Pareja, Cónyuge, Hijo Mayor o Representante Legal.

    RN4: El inventario de espacios se limita a tres opciones: Parcela, Panteón o Nicho.

    RN5: Los integrantes usan el espacio funerario exclusivamente si la cuenta del Socio Titular mantiene el estado "Aprobado".

7. Requerimientos de interfaces externas

    Interfaces de Usuario: El sistema contará con un formulario web público (para interesados) y un portal privado (para socios y administrativos).

    Interfaces de Software: Se requiere conexión a una API de pasarela de pagos externa para procesar la afiliación y el cobro mensual.

    Interfaces de Comunicación: Integración con una API de servicios de telecomunicación para el envío automático de SMS del Doble Factor de Autenticación (2FA).

8. Glosario

    Socio Titular: Cliente principal responsable financiero del grupo.

    Espacio Fúnebre: Ubicación física asignada en el cementerio (parcela, panteón o nicho).

    2FA (Doble Factor de Autenticación): Medida de seguridad que exige un código temporal enviado al celular para iniciar sesión.

    Postulante: Usuario interesado que completó el formulario web pero aún no fue aprobado.
